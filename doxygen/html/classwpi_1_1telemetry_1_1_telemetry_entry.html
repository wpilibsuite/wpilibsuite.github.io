Detailed Description

Interface for individual telemetry entries.

Intended for use by backends; most users should use the TelemetryTable class.

Implementations must not throw from logging, metadata, or discard-checking methods. Recoverable failures should be reported through TelemetryRegistry::ReportWarning() and skipped.

Methods on the same entry may be called concurrently. Implementations must copy spans and string views they retain after a method returns.
