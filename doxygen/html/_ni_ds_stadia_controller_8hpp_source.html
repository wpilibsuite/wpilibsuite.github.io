17/**
18 * Handle input from NiDsStadia controllers connected to the Driver Station.
19 *
20 * This class handles NiDsStadia input that comes from the Driver Station. Each
21 * time a value is requested the most recent value is returned. There is a
22 * single class instance for each controller and the mapping of ports to
23 * hardware buttons depends on the code in the Driver Station.
24 *
25 * Only first party controllers from Google are guaranteed to have the
26 * correct mapping, and only through the official NI DS. Sim is not guaranteed
