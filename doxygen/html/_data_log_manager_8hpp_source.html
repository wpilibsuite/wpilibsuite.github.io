23/**
24 * Centralized data log that provides automatic data log file management. It
25 * automatically cleans up old files when disk space is low and renames the file
26 * based either on current date/time or (if available) competition match number.
27 * The data file will be saved to a USB flash drive in a folder named "logs" if
28 * one is attached, or to /home/systemcore/logs otherwise.
29 * When automatic selection falls back to internal storage, USB storage is
30 * checked every 5 seconds. If it becomes available and the current file is at
31 * most 10 MB, the file is transferred in the background and logging continues
32 * on USB storage.
33 *
34 * Log files are initially named "WPILIB_TBD_{random}.wpilog" until the DS
35 * connects. After the DS connects, the log file is renamed to
36 * "WPILIB_yyyyMMdd_HHmmss.wpilog" (where the date/time is UTC). If the FMS is
37 * connected and provides a match number, the log file is renamed to
38 * "WPILIB_yyyyMMdd_HHmmss_{event}_{match}.wpilog".
39 *
40 * On startup, all existing WPILIB_TBD log files are deleted. If there is less
41 * than 200 MB of free space on the target storage, non-match WPILIB_ log files
42 * are deleted (oldest to newest) until there is 200 MB free OR there are 10
43 * files remaining, including match logs. Competition match logs and their
44 * rotated segments are not deleted. An alert is active while less than 400 MB
45 * is available, checked every 5 seconds. An
46 * informational alert indicates when automatic directory selection falls back
47 * to SystemCore internal storage.
48 *
49 * By default, all NetworkTables value changes are stored to the data log.
50 */
51class DataLogManager final {
52 public:
53 DataLogManager() = delete;

55 /**
56 * Start data log manager. The parameters have no effect if the data log
57 * manager was already started (e.g. by calling another static function).
58 *
59 * @param dir if not empty, directory to use for data log storage
60 * @param filename filename to use; if none provided, the filename is
61 * automatically generated
62 * @param period time between automatic flushes to disk, in seconds;
63 * this is a time/storage tradeoff
64 */
65 static void Start(std::string_view dir = "", std::string_view filename = "",
66 double period = 0.25);
