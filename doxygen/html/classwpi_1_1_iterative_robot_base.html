Detailed Description

IterativeRobotBase implements a specific type of robot program framework, extending the RobotBase class.

The IterativeRobotBase class does not implement StartCompetition(), so it should not be used by teams directly.

This class provides the following functions which are called by the main loop, StartCompetition(), at the appropriate times:

DriverStationConnected() – provide for initialization the first time the DS is connected

Start() functions – each of the following functions is called once when the appropriate mode starts:

  • DisabledStart() – called each and every time disabled mode starts
  • AutonomousStart() – called each and every time autonomous mode starts
  • TeleopStart() – called each and every time teleoperated mode starts
  • UtilityStart() – called each and every time utility mode starts

Periodic() functions – each of these functions is called on an interval:

  • RobotPeriodic()
  • DisabledPeriodic()
  • EnabledPeriodic()
  • AutonomousPeriodic()
  • TeleopPeriodic()
  • UtilityPeriodic()

Order within one loop iteration:

  1. DriverStationConnected(), once, the first time the DS is connected
  2. The end function of the previous mode and the start function of the new mode, only on a mode change
  3. EnabledPeriodic(), only while enabled
  4. The periodic function for the current mode (DisabledPeriodic(), AutonomousPeriodic(), TeleopPeriodic(), or UtilityPeriodic())
  5. RobotPeriodic()
  6. SimulationPeriodic(), only in simulation

The mode-specific periodic function runs before RobotPeriodic(). Exactly one mode-specific periodic function runs per iteration.

End() functions – each of the following functions is called once when the appropriate mode ends:

  • DisabledEnd() – called each and every time disabled mode ends
  • AutonomousEnd() – called each and every time autonomous mode ends
  • TeleopEnd() – called each and every time teleoperated mode ends
  • UtilityEnd() – called each and every time utility mode ends
