Detailed Description

Tachometer for getting rotational velocity from a device.

The Tachometer class measures the rate of digital pulses to determine the rotation velocity of a mechanism. Examples of devices that could be used with the tachometer class are a hall effect sensor, break beam sensor, or optical sensor detecting tape on a shooter wheel. Unlike encoders, this class only needs a single digital input.
