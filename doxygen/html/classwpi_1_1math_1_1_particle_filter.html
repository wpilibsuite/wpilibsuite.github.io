Detailed Description

template<int States, int Inputs, int Outputs>
class wpi::math::ParticleFilter< States, Inputs, Outputs >

A particle filter estimates the state of a system by representing the state distribution with a set of weighted samples called particles.

Unlike Kalman filters, it doesn't assume the state distribution is Gaussian, so it can handle strongly nonlinear models and multimodal distributions.

Each prediction step propagates every particle through the dynamics model and adds sampled process noise. Each correction step reweights the particles by the likelihood of the measurement given each particle, then resamples the particles if too few of them carry most of the weight.

The state estimate x-hat is the weighted mean of the particles, and the error covariance P is their weighted sample covariance.

The filter's computational cost is proportional to the number of particles. More particles give a more accurate approximation of the state distribution.

This class implements the generic particle filter in [2, Algorithm 3, p. 180] with the dynamics model as the importance density [2, eq. (62), p. 179]. That importance density comes from the bootstrap filter [1, Section 3.1, p. 108], also known as the sampling importance resampling (SIR) filter [2, Section V-B1, p. 181]. Unlike those filters, this one only resamples when the effective sample size is low instead of every timestep.

The N particles xᵢ with weights Wᵢ approximate the posterior state distribution as [2, eq. (49), p. 178]

p(xₖ | y₁, …, yₖ) ≈ Σᵢ Wᵢ δ(xₖ − xᵢ)

where δ is the Dirac delta and Σᵢ Wᵢ = 1.

Constructs a particle filter with custom mean, residual, and addition functions.

Using custom functions for arithmetic can be useful if you have angles in the state or measurements, because they allow you to correctly account for the modular nature of angle arithmetic (see AngleMean(), AngleResidual(), and AngleAdd()).

All particles start at the zero state, so the initial error covariance is zero. Call SetXhat() and SetP() to set the initial state distribution.

See https://docs.wpilib.org/en/stable/docs/software/advanced-controls/state-space/state-space-observers.html#process-and-measurement-noise-covariance-matrices for how to select the standard deviations.

Parameters
fA vector-valued function of x and u that returns the derivative of the state vector.
hA vector-valued function of x and u that returns the measurement vector.
stateStdDevsStandard deviations of model states.
measurementStdDevsStandard deviations of measurements.
meanFuncXA function that computes the weighted mean of the particles (one particle per column) given a column vector of weights that sum to one.
residualFuncXA function that computes the residual of two state vectors (i.e. it subtracts them.)
residualFuncYA function that computes the residual of two measurement vectors (i.e. it subtracts them.)
addFuncXA function that adds two state vectors.
numParticlesNumber of particles. Must be positive.
dtNominal discretization timestep.
Throws:
std::invalid_argument if numParticles isn't positive.
