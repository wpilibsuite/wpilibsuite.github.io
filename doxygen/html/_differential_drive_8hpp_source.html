17/**
18 * A class for driving differential drive/skid-steer drive platforms such as
19 * the Kit of Parts drive base, "tank drive", or West Coast Drive.
20 *
21 * These drive bases typically have drop-center / skid-steer with two or more
22 * wheels per side (e.g., 6WD or 8WD). This class takes a setter per side. For
23 * four and six motor drivetrains, use CAN motor controller followers or
24 * PWMMotorController::AddFollower().
25 *
26 * A differential drive robot has left and right wheels separated by an
27 * arbitrary width.
28 *
29 * Drive base diagram:
30 * <pre>
31 * |_______|
32 * | | | |
33 * | |
34 * |_|___|_|
35 * | |
36 * </pre>
37 *
38 * Each drive function provides different inverse kinematic relations for a
39 * differential drive robot.
40 *
41 * This library uses the NWU axes convention (North-West-Up as external
42 * reference in the world frame). The positive X axis points ahead, the positive
43 * Y axis points to the left, and the positive Z axis points up. Rotations
44 * follow the right-hand rule, so counterclockwise rotation around the Z axis is
45 * positive.
46 *
47 * Inputs smaller then 0.02 will be set to 0, and larger values will be scaled
48 * so that the full range is still used. This deadband value can be changed
49 * with SetDeadband().
50 *
51 * MotorSafety is enabled by default. The tankDrive, arcadeDrive,
52 * or curvatureDrive methods should be called periodically to avoid Motor
53 * Safety timeouts.
54 */
55class DifferentialDrive : public RobotDriveBase,
56 public wpi::telemetry::TelemetryLoggable {
57 public:

100 /**
101 * Arcade drive method for differential drive platform.
102 *
103 * Note: Some drivers may prefer inverted rotation controls. This can be done
104 * by negating the value passed for rotation.
105 *
106 * @param xVelocity The velocity at which the robot should drive along the X
107 * axis [-1.0..1.0]. Forward is positive.
108 * @param zRotation The rotation rate of the robot around the Z axis
109 * [-1.0..1.0]. Counterclockwise is positive.
110 * @param squareInputs If set, decreases the input sensitivity at low
111 * velocities.
112 * @Common This is one of the commonly used methods for this class
113 */
114 void ArcadeDrive(double xVelocity, double zRotation,
115 bool squareInputs = true);
116
117 /**
118 * Curvature drive method for differential drive platform.
119 *
120 * The rotation argument controls the curvature of the robot's path rather
121 * than its rate of heading change. This makes the robot more controllable at
122 * high velocities.
123 *
124 * @param xVelocity The robot's velocity along the X axis [-1.0..1.0]. Forward
125 * is positive.
126 * @param zRotation The normalized curvature [-1.0..1.0]. Counterclockwise is
127 * positive.
128 * @param allowTurnInPlace If set, overrides constant-curvature turning for
129 * turn-in-place maneuvers. zRotation will control turning rate instead of
130 * curvature.
131 */
132 void CurvatureDrive(double xVelocity, double zRotation,
133 bool allowTurnInPlace);
134
135 /**
136 * Tank drive method for differential drive platform.
137 *
138 * @param leftVelocity The robot left side's velocity along the X axis
139 * [-1.0..1.0]. Forward is positive.
140 * @param rightVelocity The robot right side's velocity along the X axis
141 * [-1.0..1.0]. Forward is positive.
142 * @param squareInputs If set, decreases the input sensitivity at low
143 * velocities.
144 */
145 void TankDrive(double leftVelocity, double rightVelocity,
146 bool squareInputs = true);

184 /**
185 * Tank drive inverse kinematics for differential drive platform.
186 *
187 * @param leftVelocity The robot left side's velocity along the X axis
188 * [-1.0..1.0]. Forward is positive.
189 * @param rightVelocity The robot right side's velocity along the X axis

191 * @param squareInputs If set, decreases the input sensitivity at low
192 * velocities.
193 * @return Wheel velocities [-1.0..1.0].
194 */
195 static WheelVelocities TankDriveIK(double leftVelocity, double rightVelocity,
196 bool squareInputs = true);

207 std::function<void(double)> m_rightMotor;

211 double m_rightOutput = 0.0;
212};
