Detailed Description

template<class Distance>
requires wpi::units::length_unit<Distance> || wpi::units::angle_unit<Distance> || wpi::units::dimensionless_unit<Distance>
class wpi::math::DCMotorBiasEstimator< Distance >

This class estimates the input bias required to make the expected motor velocity match the actual velocity over one timestep.

Subtracting this input bias from the next control input will cancel it and eliminate steady-state error. This method of fixing steady-state error is superior to a pure integral controller because it only integrates for unmodeled disturbances, not during expected transient behavior while converging to a reference. This means there won't be overshoot during transients.

The feedforward gains passed to this class should match the ones used by the mechanism's feedforward. The estimator estimates the error in that feedforward model; if the gains differ, the difference shows up as input error. In particular, errors in kV appear as an input bias proportional to velocity, and errors in kA appear as an input bias during acceleration. Logging the input bias estimate against velocity is a useful way to find these: a slope indicates kV error, and a sign flip on direction reversal indicates kS error.

Constructs a DC motor bias estimator.

The model is

a = −kV/kA·v + 1/kA·(u + d) − kS/kA·sgn(v) − kG/kA

where a is the acceleration, v is the velocity, u is the applied voltage, and d is the estimated input bias.

For an arm, whose gravity term depends on angle, pass zero for kG and subtract the gravity feedforward voltage from the voltage passed to Calculate() instead.

Parameters
kSThe static gain. This should match the feedforward's kS, or be zero if the feedforward doesn't use one.
kGThe gravity gain. This should match the feedforward's kG, or be zero if the feedforward doesn't use one.
kVThe velocity gain. Must be non-negative.
kAThe acceleration gain. Must be non-negative. kV and kA can't both be zero.
timeConstantThe approximate time for the input bias estimate to converge to a new constant input bias. Larger values reject disturbances more slowly but react less to model error and measurement noise. Must be positive.
dtNominal discretization timestep. Must be positive.
Throws:
std::invalid_argument if any of the parameter constraints are violated.
