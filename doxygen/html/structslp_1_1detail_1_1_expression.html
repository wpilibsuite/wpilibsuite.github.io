◆ scratch

template<typename Scalar_>
int32_t slp::detail::Expression< Scalar_ >::scratch = -1

Scratch space for various graph algorithms.

In expression_graph.hpp's topological_sort(), scratch counts incoming edges for this node, offset by -1 so -1 means no edges.

In Hessian and Jacobian constructors, scratch represents this expression's column in a Jacobian, or -1 otherwise.

They share a default state of -1 to avoid extra assignments.
