Detailed Description

Specifies that a type is capable of telemetry logging with a specified type.

Implementations must define two non-member functions (can be via ADL lookup) for logging to a TelemetryTable with the following signatures (as enforced by this concept):

  • std::string_view GetTelemetryTypeName(T&& value): function that returns the type name
  • void LogTo(TelemetryTable& table, T&& value): function for logging

GetTelemetryTypeName() may return types other than std::string_view, as long as the return value is convertible to std::string_view.
