1/**
2 * @file ada.h
3 * @brief Main header for the Ada URL parser library.
4 *
5 * This is the primary entry point for the Ada URL parser library. Including
6 * this single header provides access to the complete Ada API, including:
7 *
8 * - URL parsing via `ada::parse()` function
9 * - Two URL representations: `ada::url` and `ada::url_aggregator`
10 * - URL search parameters via `ada::url_search_params`
11 * - URL pattern matching via `ada::url_pattern` (URLPattern API)
12 * - IDNA (Internationalized Domain Names) support
13 *
14 * @example
15 * ```cpp
16 * #include "ada.h"
17 *
18 * // Parse a URL
19 * auto url = ada::parse("https://example.com/path?query=1");
20 * if (url) {
21 * std::cout << url->get_hostname(); // "example.com"
22 * }
23 * ```
24 *
25 * @see https://url.spec.whatwg.org/ - WHATWG URL Standard
26 * @see https://github.com/ada-url/ada - Ada URL Parser GitHub Repository
27 */
