◆ is_windows_drive_letter()

bool ada::checkers::is_windows_drive_letter ( std::string_view input)
inlineconstexprnoexcept

A string starts with a Windows drive letter if all of the following are true:

  • its length is greater than or equal to 2
  • its first two code points are a Windows drive letter
  • its length is 2 or its third code point is U+002F (/), U+005C (), U+003F (?), or U+0023 (#).

◆ try_parse_ipv4_fast()

ada_really_inline uint64_t ada::checkers::try_parse_ipv4_fast ( std::string_view input)
noexcept

Fast pure-decimal IPv4 parse.

Fast-path parser for pure decimal IPv4 addresses (e.g., "192.168.1.1").

Returns packed address or ipv4_fast_fail. Accepts an optional single trailing dot.

On AVX-512BW+VL targets, uses a masked-load SIMD kernel (no source over-read) inspired by Lemire/Mula. Otherwise uses an unrolled scalar path (typically faster than SSE2/NEON pre-validation for these 7-16 byte hosts).

Returns the packed 32-bit IPv4 address on success, or a value > 0xFFFFFFFF to indicate failure (caller should fall back to general parser). This is optimized for the common case where the input is a well-formed decimal IPv4 address with exactly 4 octets.
