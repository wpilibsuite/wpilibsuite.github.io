39/**
40 * @brief Represents a parsed URL with individual string components.
41 *
42 * The `url` struct stores each URL component (scheme, username, password,
43 * host, port, path, query, fragment) as a separate `std::string`. This
44 * provides flexibility but incurs more memory allocations compared to
45 * `url_aggregator`.
46 *
47 * **When to use `ada::url`:**
48 * - When you need to frequently modify individual URL components
49 * - When you want independent ownership of component strings
50 *
51 * **When to use `ada::url_aggregator` instead:**
52 * - For read-mostly operations on parsed URLs
53 * - When memory efficiency is important
54 * - When you only need string_view access to components
55 *
56 * @note This type is returned when parsing with `ada::parse<ada::url>()`.
57 * By default, `ada::parse()` returns `ada::url_aggregator`.
58 *
59 * @see url_aggregator For a more memory-efficient URL representation
60 * @see https://url.spec.whatwg.org/#url-representation
61 */

65 url(url&& u) noexcept = default;
