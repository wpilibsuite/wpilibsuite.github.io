242/**
243 * Return the approximate match time. The FMS does not send an official match
244 * time to the robots, but does send an approximate match time. The value will
245 * count down the time remaining in the current period (auto or teleop).
246 * Warning: This is not an official time (so it cannot be used to dispute ref
247 * calls or guarantee that a function will trigger before the match ends).
248 *
249 * <p>When connected to the real field, this number only changes in full integer
250 * increments, and always counts down.
251 *
252 * <p>When the DS is in practice mode, this number is a floating point number,
253 * and counts down.
254 *
255 * <p>When the DS is in teleop or autonomous mode, this number returns -1.0.
256 *
257 * <p>Simulation matches DS behavior without an FMS connected.
258 *
259 * @param[out] status the error code, or 0 for success
260 * @return Time remaining in current match period (auto or teleop) in seconds
261 */
262double HAL_GetMatchTime(int32_t* status);
