27/**
28 * @brief Memory-efficient URL representation using a single buffer.
29 *
30 * The `url_aggregator` stores the entire normalized URL in a single string
31 * buffer and tracks component boundaries using offsets. This design minimizes
32 * memory allocations and is ideal for read-mostly access patterns.
33 *
34 * Getter methods return `std::string_view` pointing into the internal buffer.
35 * These views are lightweight (no allocation) but become invalid if the
36 * url_aggregator is modified or destroyed.
37 *
38 * @warning Views returned by getters (e.g., `get_pathname()`) are invalidated
39 * when any setter is called. Do not use a getter's result as input to a
40 * setter on the same object without copying first.
41 *
42 * @note This is the default URL type returned by `ada::parse()`.
43 *
44 * @see url For an alternative using separate std::string instances
45 */
46struct url_aggregator : url_base {
47 url_aggregator() = default;
48 url_aggregator(const url_aggregator& u) = default;
49 url_aggregator(url_aggregator&& u) noexcept = default;
50 url_aggregator& operator=(url_aggregator&& u) noexcept = default;
51 url_aggregator& operator=(const url_aggregator& u) = default;
52 ~url_aggregator() override = default;

54 /**
55 * The setter functions follow the steps defined in the URL Standard.
56 *
57 * The url_aggregator has a single buffer that contains the entire normalized
58 * URL. The various components are represented as offsets into that buffer.
59 * When you call get_pathname(), for example, you get a std::string_view that
60 * points into that buffer. If the url_aggregator is modified, the buffer may
61 * be reallocated, and the std::string_view you obtained earlier may become
62 * invalid. In particular, this implies that you cannot modify the URL using
63 * a setter function with a std::string_view that points into the
64 * url_aggregator E.g., the following is incorrect:
65 * url->set_hostname(url->get_pathname()).
66 * You must first copy the pathname to a separate string.
67 * std::string pathname(url->get_pathname());
68 * url->set_hostname(pathname);
69 *
70 * The caller is responsible for ensuring that the url_aggregator is not
71 * modified while any std::string_view obtained from it is in use.
72 */
73 bool set_href(std::string_view input);
74 bool set_host(std::string_view input);

209 /**

218 * | | | | | `----------------- pathname_start
